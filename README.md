# Landing Page Gabriel Deble

Pacote estático pronto para GitHub Pages e para o domínio
`advgabrieldeble.com.br`.

## Publicação pelo GitHub

1. Envie **todo o conteúdo desta pasta** para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.

O arquivo `CNAME` já contém o domínio `advgabrieldeble.com.br`.

## Arquivos principais

- `index.html`: página principal;
- `styles.css`: identidade visual e responsividade;
- `script.js`: triagem e abertura do WhatsApp;
- `assets/`: logotipos e foto;
- `privacidade/index.html`: política de privacidade;
- `CNAME`: domínio personalizado;
- `robots.txt` e `sitemap.xml`: indexação.
